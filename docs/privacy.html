Privacy Policy

Last updated: 2026-09-22

Koshien Digest Bot ("this application") is a personal, non-commercial automation project that summarizes publicly available Tokai-region high school baseball game results into short videos, and publishes them to a single YouTube channel and a single Threads account owned by the developer.

Data we access

This application uses the Google OAuth API and the YouTube Data API solely to upload video files to the developer's own YouTube channel. It does not access, collect, or share any personal data belonging to end users or viewers.

Use and transfer of information received from Google APIs

This application's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Data retention

No end-user personal data is stored by this application. OAuth credentials (refresh tokens) are stored securely as encrypted secrets in the developer's private GitHub repository and are used only to authenticate the developer's own YouTube channel.
